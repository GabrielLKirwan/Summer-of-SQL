**☀️ The Summer of SQL**

Bridging the gap from SQL tutorials to real-world applications.

Welcome to The Summer of SQL! Created by Will Sutton at The Information Lab, this initiative is designed to help you build confidence in SQL, escape "tutorial hell," and develop a portfolio of skills by solving real-world problems.

Note: Despite the name, you can participate in the Summer of SQL at any time of the year!

**🎯 Why This Project?**

Learning SQL often stops at basic tutorials. It can be difficult to find environments where you can test and learn without the fear of breaking a production database.

The Summer of SQL provides a curated, progressive curriculum of challenges. It starts with fun queries and ramps up to database setup, data reshaping, and complex analysis. Each challenge comes with:

Video Walkthroughs: To help you start on the right track, fix common errors, and explore different ways to solve problems.

Solutions: To check your work and learn alternative approaches.

**📝 Prerequisites**

Before diving in, it's recommended that you have a basic understanding of SQL syntax.

Need a refresher? We highly recommend the interactive tutorials available on SQLBolt.

**🛠️ What You Will Learn**

Throughout these 10 weeks, you can expect to master techniques such as:

Joining several tables and complex ```JOIN``` operations

Common Table Expressions (CTEs), Recursive CTEs, and Subqueries

Window functions (e.g., ```ROW_NUMBER()```, ```RANK()```)

```PIVOT, ```UNPIVOT```, and splitting comma-separated strings

Setting up a local database (PostgreSQL/MySQL), importing data, and creating Entity Relationship Diagrams (ERDs)

Math, Datetime, and Scalar functions
